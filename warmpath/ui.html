Recruiters, likely hiring managers, and in-function peers from Exa's people index. Public profile URLs; you open them. Needs pip install exa-py and EXA_API_KEY in .env.

Ingest the official LinkedIn export. Settings & Privacy → Data privacy → Get a copy of your data → full archive (you want messages.csv and Positions.csv). Message content is read for counts and dates only and never stored. Everything stays in the local SQLite file shown in the header.

or drop the ZIP here (it is copied to data/upload.zip, gitignored)

Try it without your data: python -m warmpath demo then python -m warmpath serve --db data/demo.db.
